# Aerospace-Orbital-Mechanics

A collection of computational aerospace engineering and orbital mechanics simulations in Python.

## Projects Included
1. **Aircraft Performance Analysis**: Calculates range, endurance, lift, drag, and center of gravity.
2. **Rocket Dynamics**: Simulates velocity profile over time using the Tsiolkovsky rocket equation and ODE solvers.
3. **ISS Tracking & Passes**: Computes TLE orbital data, azimuth/altitude coordinates, and polar charts.
4. **Satellite Trajectory GUI**: Interactive Tkinter application for orbital element manipulation and 3D Keplerian visualization.
5. **Solar System Orbits**: 2D and 3D planetary orbit visualization using astronomical units (AU).
